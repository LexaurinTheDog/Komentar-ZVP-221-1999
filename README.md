# Komentář k zákonu č. 221/1999 Sb., o vojácích z povolání

Otevřený komentář k zákonu o vojácích z povolání — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; vznik, průběh a zánik služebního poměru, výkon služby, dovolená, kázeňské právo, služební plat a náhrady, péče o vojáky, náhrada škody, výsluhové náležitosti a rozhodování ve věcech služebního poměru.

Konsolidované znění: dokument e-Sbírky `SB-1999-00221_2025-10-01`.
